HTML

HTML son las siglas de HyperText Markup Language, que puede traducirse como lenguaje de marcas o marcado de hipertexto.

El lenguaje HTML se emplea para crear las páginas web. Es decir, por él ver el código HTML de una página web. El aspecto exacto cambia de un navegador a otro y también puede cambiar de una versión a otra de un mismo navegador, pero siempre se verá una página web.

En los equipos informáticos los códigos que se escriben entre los símbolos menor que y mayor que.

Historia de HTML

Los inicios del lenguaje HTML se remontan al año 1990, cuando Tim Berners-Lee creó la primera página web.

Versiones de HTML

Tim Berners-Lee definió la primera versión de HTML en el año 1991.

En la actualidad, la última versión de HTML es HTML5.
